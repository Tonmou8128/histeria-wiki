# Burk

## Informations
L'enchantement Burk est fusionnable avec une [épée en Histerite](https://histeria.fr/wiki/2-equipement/histerite-sword) ou une [hache en Histerite](https://histeria.fr/wiki/2-equipement/histerite-axer).
Quand un joueur frappe un ennemi, il a une chance de lui lancer une boule de feu.

**Niveau maximum :** 5

| Niveau | Pourcentage d'activation |
| --- | --- |
| 1 | 1.96 % |
| 2 | 2.45 % |
| 3 | 2.94 % |
| 4 | 3.43 % |
| 5 | 3.92 % |
