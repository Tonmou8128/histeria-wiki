# Gaze

## Informations
L'enchantement Gaze est fusionnable avec une [pioche en Histerite](https://histeria.fr/wiki/2-equipement/histerite-pickaxe). Quand le porteur mine un bloc, il a une chance de recevoir un lingot d'or ou de fer.

**Niveau maximum :** 5

| Niveau | Pourcentage d'activation |
| --- | --- |
| 1 | 0.8 % |
| 2 | 1 % |
| 3 | 1.2 % |
| 4 | 1.4 % |
| 5 | 1.6 % |
