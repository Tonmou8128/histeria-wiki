# Codex d'enchantement

## Description

Le codex d'enchantement est un objet très précieux. En effet, il permet d'améliorer un enchantement directement au niveau maximum à tous les coups.

## Mode d'emploi

Le joueur  doit se diriger vers une enclume en Histerite, située aux spawns des serveurs factions.

Il faut mettre l'objet enchanté dans la case à gauche et le codex dans la case du milieu. L'objet avec l'enchantement au maximum sera dans la case de droite.
