# Filament nocturne

## Description

Le **filament nocturne** est l'objet reçu après avoir tué un Noctus. Il a 1 chance sur 10 d'être obtenu. 

Le **filament primordial** est la variante rare du filament nocturne. Il a 1 chance sur 230 d'être obtenu.

Le filament nocturne peut être échangé à l'Hermite dans la farmzone.
