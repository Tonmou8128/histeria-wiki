# Nihil

## Informations
L'enchantement Nihil est fusionnable avec une [hache en Histerite](https://histeria.fr/wiki/2-equipement/histerite-axe).
Quand le porteur frappe un ennemi, il a une chance de lui voler 2 coeurs.

**Niveau maximum :** 5

| Niveau | Pourcentage d'activation |
| --- | --- |
| 1 | 1.98 % |
| 2 | 2.475 % |
| 3 | 2.97 % |
| 4 | 3.465 % |
| 5 | 3.96 % |
