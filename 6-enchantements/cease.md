# Cease

## Informations
L'enchantement Cease est fusionnable avec une [pièce d'armure](https://histeria.fr/wiki/2-equipement).
Quand le porteur de l'enchantement est frappé, il a une chance de renvoyer les dégâts à l'adversaire.

**Niveau maximum :** 5

| Niveau | Pourcentage d'activation |
| --- | --- |
| 1 | 0.9975 % |
| 2 | 1.14 % |
| 3 | 1.2825 % |
| 4 | 1.425 % |
| 5 | 1.5675 % |
