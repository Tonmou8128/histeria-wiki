# Marqueurs

## Description

Les marqueurs peuvent être fusionnés à un équipement, et ils affichent une information sur ce dernier. C'est un objet principalement cosmétique.

Voici leurs effets:

| Marqueur | Effet | Comptabilité |
| --- | --- | --- |
| Marqueur de joueur | Affiche le nom du propriétaire | Tout |
| Marqueur de blocs | Affiche le nombre de blocs minés | Pioche |
| Marqueur d'éliminations | Affiche le nombre d'éliminations | Epée, hache |
| Marqueur d'éliminations de créatures | Affiche le nombre de créatures éliminées | Epée, hache |
