# Rust

## Informations
L'enchantement Rust est fusionnable avec une [hache](https://histeria.fr/wiki/2-equipement/histerite-axe).
Quand le porteur frappe un ennemi, il a une chance de retirer 1.5 coeur de vie supplémentaire à son adversaire et de réduire la durabilité de son armure.

**Niveau maximum :** 5

| Niveau | Pourcentage d'activation |
| --- | --- |
| 1 | 2.475 % |
| 2 | 3.465 % |
| 3 | 4.455 % |
| 4 | 5.445 % |
| 5 | 6.435 % |
