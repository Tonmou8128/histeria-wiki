# Flatten

## Informations
L'enchantement Flatten est fusionnable avec une [pièce d'armure](https://histeria.fr/wiki/2-equipement).
Quand le porteur de l'enchantement est frappé, il a une chance de baisser le niveau des effets de résistance des ennemis alentours de 1.

**Niveau maximum :** 3

| Niveau | Pourcentage d'activation |
| --- | --- |
| 1 | 1.14 % |
| 2 | 1.425 % |
| 3 | 1.71 % |

# Obtention

Flatten n'est disponible que dans les coffres légendaires et au niveau 42 du métier de fermier.
