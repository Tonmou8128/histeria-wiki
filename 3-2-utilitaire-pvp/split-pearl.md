# Ender pearl divisée

## Description

L'ender pearl divisée est une perle de l'end qui se divise en l'air en plusieurs perles, eles sont toutes fausses sauf une vrai qui part dans une direction aléatoire. Elle est disponible à l'achat chez l'Hermite.
